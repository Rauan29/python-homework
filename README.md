# Домашка на субботу

Разбор методов:
- `lists.py` — методы списка (list)
- `sets.py` — методы множества (set)
- `dicts.py` — методы словаря (dict)

Мини-функции:
- `list_function.py` — `build_playlist()`: собирает плейлист (copy, extend, remove, count, append, index, pop, sort, insert, reverse, clear)
- `set_function.py` — `compare_friends()`: общие друзья и рекомендации (intersection, difference, discard, union, symmetric_difference, isdisjoint, issubset, add, copy)
- `dict_function.py` — `cart_total()`: чек интернет-магазина со скидкой (get, fromkeys, items, pop, values, update, setdefault, popitem, keys, copy, clear)
- `str_function.py` — `format_profile()`: приводит анкету в порядок (strip, split, join, title, lower, count, find, endswith, replace, startswith, isdigit, capitalize, rstrip, center, ljust)

Запуск: `python3 list_function.py`
